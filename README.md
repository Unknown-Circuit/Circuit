# Artificial Intelligence Demo: Expert System & Search Algorithm

Proyek ini berisi implementasi sederhana **System Pakar (Expert System)** berbasis aturan dan tiga jenis **Algoritma Pencarian (BFS, DFS, A* Search)** menggunakan bahasa Python.

## Fitur
1. **Expert System**: Diagnosis otomatis masalah hardware komputer berdasarkan gejala.
2. **Search Algorithm**: Mencari rute terpendek pada lintasan grid 5x5 menggunakan Breadth-First Search, Depth-First Search, dan A* Search.

## Prasyarat
- Python 3.x (Tidak memerlukan library pihak ketiga tambahan)
